# NLS Live Timing

A live timing broadcast overlay for the Nürburgring Langstrecken-Serie (NLS) — done, live on GitHub Pages.

**Live demo:** https://awsmoli.github.io/Live-Timing-Dashboard/

## Overview

A browser-based overlay for displaying live timing data (lap times, sector splits, standings) from Nürburgring Langstrecken-Serie races, meant to sit on top of a stream or broadcast.

Parses live timing exports (track, sector lengths, best times per class) and renders them as a clean on-screen overlay. Built with Vue 3, TypeScript, Tailwind CSS, and Vite, packaged as an installable PWA, and deployed to GitHub Pages.

Unlike most of the other sim racing projects in this portfolio, this one's actually done and in use.

## Stack

- Vue 3
- TypeScript
- Tailwind CSS
- Vite
- PWA

## Getting Started

```bash
npm install
npm run dev
```
